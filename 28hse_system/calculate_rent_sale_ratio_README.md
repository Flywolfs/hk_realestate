# 平均租售比计算脚本使用说明

## 功能概述

`calculate_rent_sale_ratio.py` 脚本用于计算28hse平台各小区的平均租售比。脚本会自动读取买卖和出租数据，剔除异常值，并计算出准确的租售比。

## 主要特点

1. **智能数据筛选**: 自动识别同时拥有买卖和出租数据的小区
2. **异常值处理**: 使用IQR（四分位距）方法剔除异常价格数据
3. **详细日志**: 完整的处理过程日志，便于追踪和调试
4. **统计信息**: 输出租售比的最小值、最大值、平均值和中位数

## 数据来源

- **买卖数据路径**: `./28hse/transaction_records_trans/buy/`
- **出租数据路径**: `./28hse/transaction_records_trans/rent/`
- **数据文件格式**: JSON格式，以小区ID命名（如`203.json`）

## 计算公式

```
租售比 (%) = (月平均租金单价 × 12) / 平均售价单价 × 100
```

其中:
- `月平均租金单价`: 从出租记录中的 `rent_per_sqft` 字段计算得出（剔除异常值后）
- `平均售价单价`: 从买卖记录中的 `price_per_sqft` 字段计算得出（剔除异常值后）

## 异常值处理说明

### IQR方法（四分位距法）

脚本使用IQR方法来识别和剔除异常值:

1. 计算数据的第一四分位数（Q1，25%）和第三四分位数（Q3，75%）
2. 计算四分位距：`IQR = Q3 - Q1`
3. 定义异常值边界:
   - 下界：`Q1 - 1.5 × IQR`
   - 上界：`Q3 + 1.5 × IQR`
4. 剔除超出边界的数据点

### 数据量要求

- 最少需要4条数据才会执行异常值剔除
- 如果剔除后某字段数据为空，该小区会被跳过

## 跳过的小区

如果某个小区满足以下任一条件，会被跳过:

1. **数据为空**: 买卖或出租数据中没有有效的价格记录
2. **剔除异常值后数据不足**: 异常值剔除后，买卖或出租数据为空

跳过的小区会在日志中显示原因和统计信息。

```
租售比 = (53 × 12) / 27859.40 × 100 = 2.2829%
```

## 依赖项

脚本仅使用Python标准库:
- `json`: JSON文件读写
- `os`, `pathlib`: 文件系统操作
- `logging`: 日志记录
- `typing`: 类型注解
- `statistics`: 统计计算

无需额外安装第三方库。

## 注意事项

1. **数据完整性**: 确保 `transaction_records_trans` 文件夹包含正确的买卖和出租数据
2. **数据格式**: JSON文件必须包含 `estate_id` 和 `transactions` 字段
3. **价格字段**: 
   - 买卖记录需要 `price_per_sqft` 字段
   - 出租记录需要 `rent_per_sqft` 字段
4. **有效值**: 脚本会自动过滤掉0、负数、None和空字符串

## 错误处理

如果遇到问题，请检查:

1. 数据文件路径是否正确
2. JSON文件格式是否正确
3. 必要的字段是否存在
4. 日志中是否有错误或警告信息
